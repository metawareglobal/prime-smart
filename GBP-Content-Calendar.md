## Google Posts: 30-day set (12 posts)

**How to use**
- Post 3 times a week (for example Monday, Wednesday, Friday). Competitors post every 1 to 2 days, so this keeps you competitive.
- Put the main keyword in the first sentence.
- Add one photo to every post (a real flag, the workshop, or work in progress). Posts with photos get far more views.
- Use a button each time: Call, or a WhatsApp/website link.
- Do not paste the exact same text twice. Vary it if you reuse a theme.
